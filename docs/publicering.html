Publicering

Jag har valt att använda GitHub Pages för att publicera min webbplats. Det är gratis och stöder HTML, CSS och JavaScript, men inte backend-språk som PHP. En fördel är att det är enkelt att använda och att man ej behöver betala något. En nackdel är att det mest passar för statiska webbplatser och inte stöder en egen backend. För att publicera webbplatsen laddar jag upp mina filer till ett repository på GitHub. Jag använder sedan GitHub Desktop för att lägga till nya filer och ändringar och skickar upp dem till GitHub. När ändringarna har laddats upp uppdateras webbplatsen automatiskt.
