CSS-Ramverk

Om laborationen

Syftet med uppgiften är att testa och jämföra olika CSS-ramverk. Jag kommer att använda Tailwind CSS och Bootstrap för att skapa en webbplats med flera undersidor. Jag kommer undersöka hur ramverken funkar, vilka fördelar och nackdelar de har och hur de kan användas för att skapa en responsiv webbplats.

Publicering

Jag har valt att använda GitHub Pages för att publicera min webbplats. Det är gratis och stöder HTML, CSS och JavaScript. En fördel är att det är enkelt att använda och att man ej behöver betala något. En nackdel är att det främst passar för statiska webbplatser och inte stöder en egen backend. För att publicera webbplatsen laddar jag upp mina filer till ett repository på GitHub. Jag använder sedan GitHub Desktop för att lägga till nya filer och ändringar och sedan skickar jag upp dem till GitHub. När ändringarna har laddats upp uppdateras webbplatsen automatiskt.
